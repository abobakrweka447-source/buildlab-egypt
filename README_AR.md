# BuildLab مصر 2.1.1 — موقع مقارنة وتجميع قطع الكمبيوتر

دي نسخة **موقع ويب جاهزة للنشر**، مش مجرد صفحة HTML قائمة بأسعار مكتوبة يدويًا.

## الموجود في النسخة

- بحث إنترنت من واجهة الموقع داخل مؤشر أسعار هاردوير مصري.
- تصنيفات موسّعة تشمل: المعالجات، كروت الشاشة، اللوحات الأم، الرامات، SSD وHDD والتخزين الخارجي، مزودات الطاقة، الكيسات، التبريد، الشاشات، اللابتوبات، الكيبورد، الماوس، سماعات الرأس والمكتبية، المراوح، UPS، الراوترات وأنظمة Mesh وAccess Points والسويتشات والفايروول ومقويات الواي فاي وأجهزة NAS والطابعات وكاميرات المراقبة وملحقات الكمبيوتر.
- ترتيب حسب السعر، وعدد العروض، والاسم، مع فلتر للعروض التي يعرض المصدر لها رابط/سعر في آخر رصد.
- بطاقات عروض تفتح صفحة البائع مباشرة وتعرض السعر الذي رُصد ورابط المقارنة الأصلي.
- زر لفحص كل عروض المنتج التي لها روابط متاجر (بحد أقصى 3 متاجر بالتوازي)، ثم إبراز أرخص عرض ظهرت له إشارة توفر مباشرة. يمكن ترتيب النتائج بالأرخص المتاح المؤكد أو تصفية النتائج التي تم التحقق من توفرها فقط. لو المتجر منع الفحص أو كانت الإشارة غير واضحة، تظهر «غير مؤكد» بدل اختراع حالة.
- مُجمّع تجميعة متعدد الخانات مع ميزانية، تعديل يدوي لسعر الحساب، حفظ محلي، تصدير ملخص، وتنبيهات توافق أولية.
- واجهة عربية RTL ومناسبة للموبايل، مع إمكانية تثبيتها كاختصار ويب على الجهاز بعد النشر.

## مصدر البيانات وحدودها

النسخة الحالية **ليست زاحفًا مستقلاً لكل متجر**: تجمع قائمة المنتجات والعروض من مؤشر مقارنة واحد، ثم تفحص صفحات المتاجر المرتبطة بالعروض مباشرة عند الطلب. هذا يضيف تحققًا لحظيًا حيث تسمح المتاجر، لكنه لا يضمن فحص كل متجر في مصر ولا أن كل منتج له عروض من أكثر من متجر.

المصدر الأساسي: https://connect4techs.com/hardware-prices/

صفحة المصدر تعلن تحديث الأسعار دوريًا (أسبوعيًا في المنهجية المعروضة)، ولذلك **الاتصال بالإنترنت لا يعني أن السعر الأصلي يتحدث كل ثانية**. الموقع يجلب قائمة المصدر عبر الخادم عند البحث، ثم يتيح محاولة فحص رابط البائع بشكل مباشر. فحص المخزون الآلي استدلالي: بعض المتاجر تستخدم صفحات ديناميكية أو تمنع الفحص؛ في هذه الحالات النتيجة «غير مؤكدة»، ولا ينبغي الاعتماد على السعر أو التوفر قبل فتح صفحة المنتج والتأكد من رقم الموديل والضمان وسعر الدفع.

هذا إصدار أول من موصل المقارنة، يعتمد على بنية صفحة مصدر عامة. إذا غيّر المصدر HTML الخاص به، قد يتوقف الاستخراج إلى حين تحديث المحلل. عند فشل المصدر لن يتحول الموقع إلى أسعار تخمينية؛ سيعرض خطأ ورابط المصدر المباشر.

## نشر الموقع (لا يتطلب مفتاح API)

المشروع يستخدم واجهات Node.js serverless، لذلك **لا يكفي رفع `index.html` وحده**. يجب نشر المجلد كاملًا على استضافة تشغّل مسارات API.

1. أنشئ مستودعًا جديدًا على GitHub.
2. فك الضغط عن الملف المرفق وارفع محتوياته بحيث تكون `index.html` و`api/` و`lib/` في جذر المستودع.
3. افتح Vercel وسجّل الدخول، ثم اختر **Add New → Project** واستورد المستودع.
4. اختَر Framework Preset = **Other** واترك أمر البناء فارغًا؛ لا يوجد build step للواجهة.
5. انشر المشروع. بعد نجاح النشر افتح رابط الموقع نفسه، وجرب البحث مثل `RTX 5070 Ti`، ثم جرّب «افحص العروض واختر الأرخص المتاح» على منتج له روابط متاجر.

المسارات البرمجية الرئيسية:

- `index.html`: الواجهة وتجميع القطع.
- `api/search.js`: جلب قائمة الأسعار وفلترتها وترتيبها.
- `api/health.js`: اختبار إن خدمة الموقع منشورة وترد بشكل صحيح.
- `api/verify.js`: محاولة فحص صفحة العرض.
- `lib/shared.js`: تحليل المصدر وتصنيف القطع والأسعار.
- `tests/parsing.test.cjs`: اختبار محلل الأسعار بعينة HTML.

## الاختبار محليًا

بعد تثبيت Node.js 22، من جذر المشروع:

```bash
npm install
npm test
```

للمعاينة البصرية فقط افتح `index.html` في المتصفح. البحث الفعلي لا يعمل في وضع `file://`؛ يلزم تشغيل الواجهة وواجهات API من خلال استضافة أو خادم يدعم المسارات.

## الخصوصية

اختيارات التجميعة محفوظة في `localStorage` على المتصفح. لا يوجد تسجيل حساب أو سلة دفع. عند البحث، يطلب الخادم صفحة المصدر، وعند اختيار «افحص الصفحة الآن» أو «افحص العروض واختر الأرخص المتاح»، يطلب الخادم روابط المنتجات من نطاقات المتاجر المدعومة.
